# 桌面宠物助手 — 设计文档

- 日期：2026-10-21
- 状态：草稿（已完成 builder 审查，待用户确认）
- 负责人：suweidong

## 意图与为什么

一个常驻、低占用的 Windows 11 桌面陪伴助手，帮一个事情很多的用户把活干完。它平时以一个小机器人悬浮在桌面上（默认右下角）；点一下它，就近在上方弹出一个紧凑的标签面板，里面是 agent 对话（Claude/Codex/OpenCode）加代办和提醒，以后还能再扩 tab。宠物的姿态本身就是状态指示（空闲 / 工作中 / 需要你），所以助手一直"在那儿"，却不用扛一个笨重的应用窗口。

为什么做：用户要同时处理很多事，想要一个一直在线、低门槛的帮手——比开一个完整 app 或浏览器标签更轻，但比一个光秃秃的托盘图标更有存在感。

## 目标

- 单个 `.exe`，在 Windows 11 上独立运行；数据放在 exe 同级目录（便携）。
- 常驻 / 驻留托盘；可最小化到托盘；点托盘恢复。
- 悬浮、置顶、透明的机器人浮层（除机器人本体外鼠标穿透）。
- 点机器人 → 在它上方弹出标签面板；面板可拖动、可缩放，视觉上与机器人连为一体（不分离）。
- 标签（v1）：对话（agent 对话）、代办（todos）、提醒（reminders）、设置（settings）。以后可加更多 tab。
- agent 对话：能跟 Claude / Codex（及类似 agent）对话，可切换；支持多会话、历史留存可续接、流式输出。
- 低资源：空闲内存小，空闲 CPU ≈ 0（睡觉 = 静态帧，不跑动画循环）。
- 简单的 2D 机器人，带一组与工作状态和氛围活动挂钩的动画状态。
- 跟随活动的反应限频：最短 15 分钟，可配置，可选随机。

## 非目标 / 反目标

- v1 不跨平台（只 Windows 11 就行）。
- 不是完整聊天客户端；不替代 Claude/Codex 应用。
- 不是多用户或云端同步；单机、本地数据。
- 不是精致的 3D / Live2D 宠物——只是简单 2D 机器人。
- 反目标：高空闲 CPU/内存（因此排除 Electron 和打包的 Python）。
- 反目标：吵闹 / 动画过度的宠物，在专注时打扰人。

## 约束

- Windows 11。系统自带 WebView2（Tauri 依赖它）；为保险起见打包时附带 WebView2 引导程序。
- 便携：数据目录默认就是 exe 所在目录。
- 技术栈：Tauri（Rust 后端 + WebView2 前端，用 TypeScript/Svelte 写界面）。已由用户锁定。
- API key / 凭证只留在本地（exe 同级的配置文件里），绝不烤进二进制、也不暴露给 webview。
- 必须支持"专注 / 勿扰"模式：静音氛围动画和非关键通知。

## 已敲定的部分（你的决定）

- 宠物：一个简单机器人。会动，状态与工作进度挂钩。
- 宠物状态（已通过）：
  - **睡眠**——长时间无任务，变暗、垂头、`Zzz`。
  - **待命**——醒着但没事，偶尔眨眼 / 环顾。
  - **思考 / 处理中**——agent 在跑；头顶齿轮转或 `...` 跳动。
  - **有动静**——任务完成或提醒到了；精神一下，冒 `!`。
  - **需要你**——出错或等你拍板；变 `?`、看你。
  - **跟随活动**——你敲键盘 / 动鼠标时偶尔瞄一眼 / 小小抖一下（≥15 分钟，可配置，可选随机，下限 15 分钟）。
  - **打哈欠**——持续空闲后过渡到睡眠。
  - **被点击**——精神一下（面板弹出的前奏）。
  - **代办清空**——所有 todo 清掉时小庆祝一下。
- 跟随活动：最短 15 分钟，可配置，可选随机（随机的下限 = 15 分钟）。
- 面板：单窗口，**标签在顶部**（不是侧边竖栏）。窗口与机器人连为一体（气泡式，带小三角连接）。可拖动、可缩放。
- 宠物可拖动重定位。
- 技术栈：Tauri。

## 架构

[builder 判断] 界面框架：**Svelte**（运行时小，契合 Tauri；备选 SolidJS）。

两个 Tauri 窗口：

1. **宠物浮层窗口**——透明、无框、置顶、不显示在任务栏、除机器人本体外鼠标穿透。承载机器人的 SVG/CSS 动画。常开。机器人本体**可拖动**重定位宠物（默认右下角；位置存进配置）。拖动 = 抓机器人本体；周围的透明区仍保持穿透。面板弹出时按离屏幕边的远近，自动翻到宠物的上方 / 下方 / 左 / 右。
2. **面板窗口**——标签助手窗口；点机器人时在其上方创建/定位；可缩放、可拖动（`start_dragging` + 可缩放配置）；默认失焦隐藏（可配置）。默认不置顶（可配置）。

**托盘**（Tauri 托盘图标）= 睡着的机器人。菜单：显示/隐藏、设置、退出。托盘左键 → 若面板隐藏则恢复，否则切换宠物可见；右键 → 菜单。

**Rust 后端**职责：

- 宠物状态机：从信号（agent 忙、提醒到期、出错、空闲时长、用户活动、勿扰）推导当前状态，推给宠物窗口。
- 定时器 / 调度：提醒触发；跟随活动节流（≥15 分钟，可配置，可选随机在 `[15, max]`）。
- 活动监测：轻量的输入空闲检测（Win32 `GetLastInputInfo`）来判断活跃 vs 离开——**不是**按键记录器；只用空闲计时，且限频。驱动跟随活动和睡眠过渡。
- agent provider 层：multica 风格——统一的 Rust `Backend` trait + 每 agent 一个子进程后端（见 Agent 接入）。
- 持久化：exe 同级的本地存储。
- 通知：提醒用 Windows toast，配合一次宠物状态变化。
- 配置：在 exe 同级加载 / 保存 TOML 或 JSON 配置（托盘开关、跟随活动间隔、provider/凭证、主题、勿扰时段）。

**前端**（TS + Svelte）：

- 面板 UI：顶部药丸式标签栏；每个 tab 一个视图；对话视图带 provider 选择器（Claude/Codex/OpenCode）、消息列表、输入框。
- 宠物窗口：SVG 机器人 + CSS 状态类，状态间有过渡。睡觉 = 静态帧（不开 `requestAnimationFrame` 循环）→ 空闲 CPU ≈ 0。

## 宠物与状态机

状态与过渡如上"已通过"那组。实现要点：

- 每个状态 = 一个 SVG 姿势 +（可选）一段轻量 CSS 关键帧循环。只有 **待命 / 思考 / 处理中** 会动；**睡眠 / 需要你 / 有动静** 近乎静态（最多偶尔慢眨眼，或完全不动）。
- Rust 状态机是唯一真相源；宠物窗口只是反映它。
- 勿扰模式强制睡眠 / 安静，并压制氛围动画 + 非关键通知。
- "状态即指示"：不另挂徽章——姿态（`!`、`?`）本身就是通知。

## 界面与窗口模型

- 面板：顶部药丸标签 `[对话][代办][提醒][设置]`；当前 tab 显示其视图；非当前 tab 是标签。
- 对话视图：输入框旁的 provider 选择器（Claude/Codex/OpenCode…）；消息气泡；**流式输出**（token / 事件逐段刷进界面，与 multica 跟智能体聊天的体验一致）；**多会话**——可开多个独立对话、在列表里切换；**历史留存可查看**——所有会话存进本地、随时翻回去看；**同一会话继承历史**（多轮，像在本地 TUI 里持续对话，后端按会话 id 续接，见 Agent 接入）。跨 tab 动作（如“把这段发到代办”）以后再做。
- 面板 ↔ 宠物：面板从宠物上方弹出（保留小三角连接）。若面板被拖走，宠物留在原地；关掉面板，宠物回到氛围态。
- 可缩放：强制一个最小尺寸；上次尺寸 / 位置存进配置。

## Agent 接入

照搬 multica 的做法（参考：`C:\Users\icsl\Desktop\github\multica-0.6.5\server\pkg\agent`）：一个统一的 Rust `Backend` trait + 每 agent 一个后端结构体，各自 spawn 用户本机已装的 CLI、解析它原生的流式输出。**不走 API key**——复用用户已有的 CLI 登录态，所以零密钥管理。

    trait Backend {
        async fn execute(&self, prompt: &str, opts: ExecOptions) -> Result<Session>;
    }
    // Session 流式吐出统一的 Message 事件（text / thinking / tool-use /
    // tool-result / status / error），以及一个最终 Result（状态、token 用量、
    // 供续接的 session_id）——与 multica 的 Session 同构。

v1 的 provider（已确认：opencode + claude + codex）：

| Agent | 调用方式 | 流格式 | 重量 |
|---|---|---|---|
| claude | `claude -p --output-format stream-json --input-format stream-json`，prompt 走 stdin | stream-json 事件 | 轻（一次性） |
| opencode | `opencode run --format json --dangerously-skip-permissions`，prompt 走 stdin（刻意不走 argv，避开命令行长度上限） | json 事件 | 轻（一次性） |
| codex | `codex app-server --listen stdio://`——长驻 JSON-RPC（initialize 握手、turn 生命周期） | app-server JSON-RPC | 重（长驻） |

要点：

- claude 与 opencode 是一次性子进程（prompt 走 stdin、stdout 吐事件）——是三个里较好移植的两个。
- codex 是 stdio 上的长驻 app-server，有握手 / turn 生命周期——三个里最重（multica 的 `codex.go` 远最长，全是超时 / 握手逻辑）；这里要多预留工作量。
- 配置：可执行路径在 PATH 上探测（可用配置 / 环境变量覆盖，对应 multica 的 `MULTICA_<X>_PATH`）；env 透传。
- 一份 `SupportedTypes` 式白名单 + 工厂，让以后加 agent（cursor/copilot/gemini）就是加一个后端文件。
- 前端流式显示 token；Rust 后端持有子进程，向 webview 吐统一的 `Message` 事件——webview 绝不直接驱动 CLI。
- **会话与历史**：对话是第一公民——多会话、持久化、可续接。每个会话存一个 agent 原生的 session/thread id（claude 的 `--resume <id>`、opencode 的 session、codex 的 thread），下一轮用它续接，镜像 multica 的 `ResumeSessionID`；agent 不支持续接时，回退成把历史消息作为上下文重放。历史与 session_id 都进 SQLite。
- **流式输出**：后端把 agent 子进程的统一 `Message` 事件实时推给前端，token / 事件逐段刷进对话视图（与 multica 跟智能体聊天的流式体验一致）。
- 以后可选：模型探测（跑 `claude models --json` 等）。

## 数据与持久化

[builder 判断] 用 **SQLite**（`rusqlite`）存结构化数据：代办、提醒、**对话与历史（多会话、每会话的 agent session/thread id、消息流）**、宠物状态日志。配置 + 凭证放 exe 同级的 TOML/JSON 文件。全部在 exe 目录下（便携）。（备选：v1 用 JSON 更简单；我选 SQLite 是因为提醒 / 历史要查询。）

## 资源策略

- 睡觉 = 静态帧，不开动画循环 → 空闲 CPU ≈ 0。
- 氛围动画短且稀疏；不开连续的 `requestAnimationFrame`。
- Rust 核心是事件驱动（定时器 + OS 空闲信号），不轮询。
- WebView2 共享；只有两个小窗口。
- 目标空闲内存 ~50–100 MB（Tauri/WebView2），空闲 CPU 趋近 0——远低于 Electron，满足低资源目标。

## 打包与分发

- Tauri 构建 → 单个 `.exe`（可选附带 WebView2 引导程序，这样没预装 WebView2 的机器也能跑）。
- 便携：首次运行在 exe 同级建数据目录；设置 / 提醒 / 历史都放那。
- 不需要安装器（需要的话也能产出）。

## builder 审查后敲定的（作为 builder 判断）

builder 审查后，下列用合理默认值敲定——有不对的请标出：

- **面板隐藏用 `hide()`，不 destroy。** 面板"失焦隐藏"时窗口保持存活。Rust 后端持有每一路 agent 流并缓存进行中的响应；若面板在流跑到一半时隐藏，流继续跑，面板重新打开时显示已完成 / 进行中的消息。隐藏绝不丢流。
- **面板打开时的 z 序。** 面板从宠物上方打开时，它变为置顶（在宠物浮层之上）并接收所有点击；宠物浮层的可交互区只有机器人本体（透明区穿透，面板打开时即穿透到面板）。小三角连接由面板窗口绘制。宠物继续动，视觉上就坐在打开面板的正下方。
- **状态清除。** `有动静`（`!`）过几秒自动清，或用户一打开面板就清。`需要你`（`?`）持续到用户交互（打开面板或显式消除）才清——它绝不自动消失，因为它的意思就是"需要你关注"。
- **便携回退。** 数据放 exe 同级（便携）。若 exe 目录只读（如 Program Files），回退到 `%APPDATA%\sss-pet`，并弹一次 toast 说明这次回退。
- **托盘左键。** 左键 = 面板隐藏则恢复，否则切换宠物可见。右键 = 上下文菜单（显示/隐藏、设置、退出）。
